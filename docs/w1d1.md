## 一、术语标准答案

### 1. 缩进
Python 用缩进表达代码块，代替其他语言的大括号；同一个代码块内缩进必须一致（推荐 4 个空格），空格与 Tab 混用会报 `IndentationError`。

### 2. 可迭代对象
能用 `for` 逐个取出元素的对象，例如 list、str、dict、set、range、文件对象。本质是实现了 `__iter__`，`for x in obj` 就是不断取下一个元素直到结束。

### 3. range(1, 101)
你的答案：只能取到 1，取不到 101。
**订正**：`range` 是**左闭右开**，取到的是 1 到 100，**不是只取到 1**。100 能取到，101 取不到。所以"从 1 到 n"要写 `range(1, n + 1)`；同理切片 `s[起点:终点]` 也取不到终点。

### 4. break 与 continue
- `break`：直接跳出整个循环，后面的轮次都不执行 —— 适合"找到就停"，如素数判断找到因数、查找命中目标
- `continue`：跳过本轮剩下的语句，进入下一轮 —— 适合"过滤"，如日志解析时跳过不合格式的脏行

### 5. 函数：def / 参数 / 返回值
`def` 定义函数，参数是入口（可以是 0 个或多个），`return` 把结果交回调用处并立刻结束函数。没有参数的函数也能有返回值。

### 6. 没有 return 时函数返回什么
你的答案：None —— 正确。

### 7. 真值判断
`if lst:` 依赖"真值"：空容器、`0`、`""`、`None`、`False` 都算假，其余算真。
与 `if len(lst) > 0` 结果相同，但前者更简洁（Pythonic）。
注意区别：`if x:` 对 `x = 0` 判假；要区分"非 None"应写 `if x is not None:`。

### 8. f-string
`f"{i*j}"`，前缀 `f` 表示格式化字符串，花括号内的表达式会先求值再转成文本填入；后面可加格式，如 `{x:2d}`、`{x:.2f}`。Python 3.6 起支持。

### 9. 局部变量与全局变量
函数内部赋值的变量默认是局部变量，函数外定义的是全局变量。函数内**读取**全局可以直接读；函数内**赋值**同名变量、又不加 `global` 声明，就会新建一个局部变量，看起来像"改了全局其实没改"，这是最常见的坑。

### 10. 整数除法 // 与取余 %
你的答案：3、1、-3。
**订正**：`7 // 2 = 3` ✔、`7 % 2 = 1` ✔、`-7 // 2` 应为 **-4**，不是 -3。
原因是 `//` 是**向下取整**（往更小的方向取整），-3.5 向下取整是 -4。
再补一个：`-7 % 2 = 1`（Python 的余数符号跟除数一致）。除数为 0 会抛 `ZeroDivisionError`。

## 二、切片补充

- 完整形式：`s[起点:终点:步长]`，**左闭右开**
- 省略起点/终点：起点默认 0，终点默认到末尾
- `s[::-1]` 为什么能反转：两个索引都省略 + 步长 -1 = 从末尾往左一路取到底
- `s[:2] + s[2:] == s` 说明了：切片互不重叠地覆盖整串；同时说明**切片越界不报错**（`s[4:42]` 直接给到末尾），而单下标越界会报 `IndexError`

## 三、疑问清单（标准答案）

**Q1：为什么 `seen` 必须是 `set()`，不能 `set(lst)`？**
`set()` 是空集合，当作"已出现过"的记录本，边遍历边 `add`。若写 `set(lst)`，一开始就把所有元素装满了，`x not in seen` 永远是 False，结果列表会是空的。
另注意：空集合只能写 `set()`，`{}` 是空字典。

**Q2：为什么 `return True` 必须写在循环外？**
写在循环里，第一次试除不整除就会立刻判定"是素数"，例如 9 在 i=2 时不整除就返回 True，判错了。正确逻辑是：循环内只在**找到因数时** `return False`；全部试完都没找到，才在循环外 `return True`。

**Q3：`range` 的终点为什么要 `+1`？**
`range` 左闭右开、不含终点。`int(n ** 0.5)` 是向下取整，例如 n=49 得 7，要覆盖到 7 就必须写 `range(2, 7 + 1)`，否则 i 只到 6，漏掉因数 7。

**Q4：`append` 和 `add` 有什么区别？**
`append` 属于 list，`add` 属于 set，不能互换，写错会报 `AttributeError`。两者都是原地修改、返回 `None`，所以不能写 `result = result.append(x)`。

**Q5：闰年为什么"能被 4 整除"还要"不能被 100 整除"？**
回归年约 365.2422 天，只按 4 年一闰（365.25 天）每年多 0.0078 天，约 128 年多 1 天。所以整百年不闰（每 100 年扣 1 天），能被 400 整除的再闰（400 年补回 1 天），平均 365.2425 天。

**Q6：`n ** 0.5` 是根号 n 吗？**
是。`**` 是幂运算，0.5 次方即平方根（因为 √n × √n = n）。等价写法有 `math.sqrt(n)`、`pow(n, 0.5)`。注意 `-2 ** 2` 是 `-4`，`**` 优先级高于单目负号。

**Q7：循环反转和切片反转有什么差别？**
结果相同。切片一次生成新字符串，复杂度 O(n)；循环版 `result += s[i]` 每次都新建字符串，复杂度 O(n²)。工程上用切片，面试要求手写循环是为了考基本功。

**Q8：`seen = [], set()` 和 `seen = set()` 是一回事吗？**
不是。`result, seen = [], set()` 是**多元赋值**，等价于 `result = []` 与 `seen = set()` 两行。
若写成左边只有一个变量 `seen = [], set()`，`seen` 会变成元组 `([], set())`，后面 `seen.add(x)` 报 `'tuple' object has no attribute 'add'`。

**Q9：需要用户输入一个数，用什么函数？**
`input()`，返回**字符串**，要算数必须 `float(...)` 或 `int(...)` 转一次；用户乱输会抛 `ValueError`，要 try/except 兜住。
规矩：`input()` 放在调用处（函数外），不要写在被自测的函数里，否则断言执行时会卡在等键盘输入。

**Q10：什么是素数？**
大于 1 的整数，只能被 1 和自己整除（恰好两个正约数）。1 不是素数，2 是唯一的偶素数。
判断只需试除到 √n：若存在大于 √n 的因数 a，必有一个小于 √n 的因数 b（a * b = n），试到 √n 就够。

## 四、今晚 10 题的一句话要点（面试可复述）

1. 乘法表：`range(1, 10)` 管行，`range(1, i + 1)` 管列，列数随行号走
2. 求和：循环累加，用 `sum(range(1, 101)) == 5050` 验证
3. 素数：试除到 √n 就够，`return True` 必须在循环外
4. 反转：索引倒序 `range(len(s)-1, -1, -1)`；切片仅用于对比版
5. FizzBuzz：先判 15 的倍数，顺序错了 15 会被 3 抢走；返回字符串不是打印
6. 去重：list 保顺序 + set 查重，两个容器分工
7. 最大值：候选值取 `lst[0]` 而不是 0，否则全负数列表会错
8. 温度转换：`c * 9 / 5 + 32`，注意 `/` 不是 `//`
9. 闰年：`year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)`，括号里是 or
10. 四则运算：if/elif 分支，除数为 0 返回提示字符串而不是崩掉
