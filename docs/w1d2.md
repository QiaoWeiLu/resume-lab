## 一、set 方法速查

| 用法 | 作用 | 注意 |
|---|---|---|
| `set()` | 创建空集合 | `{}` 是空字典，不是空集合 |
| `{1, 2, 3}` | 字面量创建 | 重复元素自动去掉 |
| `x in s` | 成员检测 | O(1)，这是 set 最大的用处 |
| `s.add(x)` | 加单个元素 | 已存在则无变化，不报错 |
| `s.update(可迭代)` | 批量加 | `s.update("abc")` 加的是 a、b、c 三个字符 |
| `s.remove(x)` | 删一个 | 元素不存在 → `KeyError` |
| `s.discard(x)` | 删一个 | 元素不存在 → 静默不报错（清理数据更省心） |
| `s.pop()` | 随机弹出一个 | 集合无序，别指望弹哪个 |
| `s.clear()` | 清空 | |
| `a \| b` / `a & b` / `a - b` / `a ^ b` | 并 / 交 / 差 / 对称差 | 教程 5.4 里的重点 |

一句话记：**查重用 `in`，加用 `add`，批量加用 `update`，删用 `discard`。**

## 二、dict 方法速查

| 用法 | 作用 | 注意 |
|---|---|---|
| `d = {}` | 空字典 | 与空集合相反 |
| `d[key]` | 取值 | 键不存在 → `KeyError` |
| `d.get(key)` | 取值 | 键不存在 → 返回 `None`，不报错 |
| `d.get(key, 默认值)` | 取值 | 键不存在 → 返回你给的默认值 |
| `d[key] = value` | 新增/修改 | 键存在就覆盖，不存在就新增 |
| `key in d` | 判断键是否存在 | 注意是判断**键**，不是值 |
| `del d[key]` | 删除 | 键不存在 → `KeyError` |
| `d.keys()` / `d.values()` / `d.items()` | 键视图 / 值视图 / 键值对视图 | 配合 for 遍历 |
| `d.setdefault(key, 0)` | 取键，不存在则先设默认值 | 计数时常用，可省一次 if 判断 |

一句话记：**不确定键在不在，就用 `get`，不要用 `d[key]`。**

## 三、四个必答问题

**1. 什么时候该用 `set` 而不是 `list`？**
需要①去重、②快速判断“某个东西是否存在”、③做集合运算（并交差）时用 set；需要保持顺序、按下标访问、允许重复时用 list。
`x in list` 要逐个扫（O(n)），`x in set` 靠哈希直接定位（O(1)），数据量大时差别明显。
我自己的话：只判断在不在而对排序无要求时用set（）

**2. `d.get(k)` 和 `d[k]` 什么时候必须用前者？**
键可能不存在时必须用 `get`。例如统计词频时第一次遇到的词还不存在，`d[word] += 1` 会先抛 `KeyError`；用 `d[word] = d.get(word, 0) + 1` 就安全。
`d[k]` 适合“键一定存在”的场景，写起来更短。
我自己的话：不确定k中是否有对应的键时用get（）

**3. `for k, v in d.items()` 里的 `k, v` 是什么语法？**
是**多元赋值/解包**，和昨晚的 `result, seen = [], set()` 同一套机制。`items()` 每次给出一对 `(键, 值)`，元组自动拆给两个变量。
等价写法：`for pair in d.items(): k, v = pair`。
我自己的话：字典中的键值对分别拆给k，v

**4. 统计词频，为什么字典比列表合适？**
列表按下标存，词和位置的对应关系是“猜不出来”的；字典是“词 → 次数”的直接映射，`d[word] = d.get(word, 0) + 1` 一步完成累加，查找也是 O(1)。
列表硬要做只能存 `(词, 次数)` 元组，每次累加还要先遍历找位置，复杂度 O(n²)。
我自己的话：这个问题不理解

## 四、为什么 set 里的元素必须可哈希、不能放列表

集合靠元素的哈希值决定存在哪个槽位。要求元素**不可变、哈希值稳定**：内容一变哈希就变，集合再也找不到它。
- 可哈希：数字、字符串、元组、`frozenset`、`None`
- 不可哈希：`list`、`dict`、`set`（都是可变的）

所以 `{[1, 2]}` 会报 `TypeError: unhashable type: 'list'`。要放一组值，先转元组：`{(1, 2)}`。
